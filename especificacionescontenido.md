# Especificaciones del Canal de Contenido

## 1. Concepto general
El proyecto de desarrollo es la **excusa** para montar el canal. No todo el contenido gira exclusivamente en torno al proyecto en sí; el proyecto es el vehículo para generar contenido de forma constante.

## 2. Narrativa técnica
- Cada vez que se muestre un **cambio** en el video, se debe explicar **para qué sirve** ese cambio, no solo mostrarlo.
- Si en pantalla aparece algo técnico específico (ej. OAuth, JSON Web Token), se debe **explicar inmediatamente** qué es y cómo funciona.
- Esto permite matar dos objetivos con una sola grabación: mostrar avance del proyecto + enseñar un concepto.

## 3. Fragmentación de contenido
- Un mismo tema puede dar para **varios videos**. Ejemplo: si se va a explicar un módulo, se puede sacar un video del frontend, otro del backend, y así dividir en partes.
- Esto multiplica la cantidad de contenido disponible para publicar a futuro.

## 4. Estética audiovisual
- **Animaciones**: tipo streaming.
- **Sonidos**: los sonidos populares que se vayan añadiendo (ya contemplados).
- **Subtítulos**: generados según los complementos ya integrados.

## 5. Formatos de salida
- **Video largo**: la pieza principal.
- **Shorts / Reels**: se extraen del video largo posteriormente, usando una app externa o una herramienta nueva por definir.
- **Modo móvil**: para shorts.
- **Modo normal**: para YouTube, Facebook u otras redes.

## 6. Estructura de edición
- Mostrar el proyecto: código, estructuras, explicación de conceptos.
- El usuario aparece en una esquina de la pantalla (arriba o abajo), tipo avatar, para dar mayor cercanía y atracción al contenido.
- Narración con voz propia del usuario.

## 7. Repositorio e identidad
- Se creará un **nuevo repositorio en GitHub** que incluirá: imágenes, videos del proyecto, la voz del usuario y su rostro representado como animación (modificable si se desea).
- **Nunca se menciona el nombre real** del usuario. Únicamente se usa el nombre: **anbo2019**.

## 8. Apoyo en producción
- Para la narración y generación de ideas conforme avance cada video, se usarán los complementos ya integrados por el usuario.
